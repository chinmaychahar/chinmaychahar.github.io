An accessibility tool that processes images and converts text to speech, making digital content more accessible.

### Features

- OCR text extraction
- Text-to-speech conversion
- Multi-language support
- User-friendly interface

### Tech Stack

- React.js
- Tesseract.js
- Web Speech API
